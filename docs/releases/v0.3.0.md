# SoftClone v0.3.0 — Installed Apps 2.0 (first milestone)

This release improves discovery and source selection without claiming to clone every installed application.

## Highlights

- Added optional **publisher** and **version** metadata from installed-program registry records on Windows.
- Search by application name, publisher, version and path, with **All / Profile-ready / Requires review / Missing executable** filters.
- Extracts real Windows executable icons on a bounded background worker, with clean vector fallbacks when artwork is unavailable.
- Added native **Choose executable** and **Choose folder** dialogs in Create clone.
- Expanded automated tests covering discovery filters, safe search, and existing clone workflows.

## Download

Select the archive for Windows x64, macOS Apple Silicon ARM64, or Linux x64, and verify with SHA256SUMS.txt. These builds contain executables, not signed installers.

## Compatibility

Native app icons currently cover supported Windows executables; macOS/Linux use fallback iconography. Microsoft Store/MSIX package enumeration is not included yet, nor are isolated services, drivers, DRM or vendor license bypasses. Apps without a known usable executable remain read-only inventory entries. For unrecognized applications, profile-only isolation is experimental.
