# SoftClone v0.2.2

Maintenance release: responsive, reusable desktop form components.

## Changes

- Extracted reusable egui form controls into separate `src/components` modules.
- Rebuilt **Discover apps** toolbar with the search icon inside its input, Rescan as a distinct button, and scanning/status information on a separate line.
- Added responsive application cards with wrapped names, notes and file paths.
- Extracted **Create clone** into source application, instance details, strategy and submit components with shared labels, inputs, spacing and helper text.
- Disabled form submit until required source path and clone name are present; kept existing backend validation and Rune name suggestions.
- Avoided repeated scan scheduling when discovery returns an empty result.

## Downloads and limitations

Binary archives are provided for Windows x64, Linux x64 and macOS Apple Silicon (ARM64), with SHA-256 checksums. These are executables, not signed installers. Installed-app discovery and clone compatibility retain the restrictions described in v0.2.1; SoftClone is not full OS virtualization.
