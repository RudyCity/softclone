# SoftClone v0.2.0

SoftClone is a native Rust desktop app for preparing additional local application instances on Windows, macOS and Linux.

## Highlights

- **Discover apps:** inspect common installed applications without launching them.
- **Portable copies:** copy self-contained executables, folders, AppImages and compatible macOS app bundles.
- **Profile-only mode:** keep installed app binaries in place and prepare new local data directories.
- **Browser adapters:** known Chromium-based browsers use `--user-data-dir`; Firefox uses explicit profile arguments.
- **Rune naming rules:** suggest instance names with the embedded Rune engine.
- **Local first:** no server, account, credential import, or privilege elevation.

## Download

Choose the binary archive for your operating system and review SHA256SUMS.txt. Archives contain an executable rather than a signed installer. macOS binaries are not notarized. On Linux you may need system graphics packages and AppImage FUSE prerequisites for applications launched through SoftClone.

## Compatibility and limitations

This is an **early compatibility release**, not a full application virtualization product. A copied installation may still depend on registry entries, shared services, drivers, activation, platform security policy, or vendor licensing. Profile-only mode is best effort for unknown applications and may reuse settings unless the app honors its environment. Use the compatibility notes in the Discover view and only copy software you are licensed to duplicate.

The source code and full documentation are available in this repository.
