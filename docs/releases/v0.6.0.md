# SoftClone v0.6.0 — full desktop migration to Tauri 2

The desktop host and complete UI have been migrated from egui/eframe to **Tauri 2**, retaining the existing Rust clone/registry engine and the embedded Rune naming interpreter.

## Desktop features

- New full-width local desktop layout with responsive navigation, native command bridge and offline frontend.
- My clones, Create clone, Discover apps, Debug logs, How it works and About pages.
- Safe native file/folder dialogs; copy preflight, background worker, byte progress and cancellation.
- Launch/stop/restart for **managed child processes**; rename/duplicate/backup/restore/delete guarded by the existing Rust engine.
- Windows Store/MSIX application activation remains an open-app operation rather than cloning.
- Apache-2.0 LICENSE and NOTICE remain part of the project and bundle.

## Compatibility and constraints

The persisted instance registry is intentionally unchanged. Existing profiles and app copies can be loaded by the new host. No vendors' files or services are modified, and no DRM, license or sandbox bypass is introduced.

**Validation:** GitHub Actions runs Rust format, Clippy and tests, checks JavaScript syntax, and compiles/bundles the Tauri app for Windows, macOS and Linux. UI runtime/installer behavior requires OS-level end-to-end testing. A successful commit alone is not proof of a working native app.
