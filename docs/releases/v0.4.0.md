# SoftClone v0.4.0 — Smart Clone Engine

Portable cloning now has a real progress indicator, read-only preflight inspection and cooperative cancellation.

## What's new

- **Preflight:** analyze selected files before cloning, estimating size and file count and rejecting unsafe symbolic links or unsupported source file types.
- **Live progress:** show bytes copied, file counts, current filename and percent complete while streaming copies.
- **Cancellation:** request cancellation while copying; incomplete files in staging are cleaned up. The original application is not modified.
- **Failure cleanup:** staging is rolled back on errors. If saving the completed instance registry entry fails, SoftClone attempts to remove the newly created instance.
- **Backward compatibility:** existing profile-only mode, saved clone registry and the original Rust clone API remain supported.
- **Tests:** added preflight, early cancellation, mid-copy cancellation and symlink safety integration tests.

## Installation

Download the Windows x64 ZIP, Linux x64 TAR.GZ or macOS ARM64 TAR.GZ. Verify with SHA256SUMS.txt. These are portable executables, not signed installers.

## Limits

Preflight estimates can change before the copy starts. Cancellation is cooperative. Custom copying preserves executable file permissions but may not retain all extended metadata, timestamps or vendor signatures. Installed application profile isolation remains best-effort except for supported browser adapters. OS virtualization, MSIX launch support and license/DRM bypass are not included.
