# SoftClone v0.2.1

**Maintenance release — installed application discovery and native UI icons.**

## Fixed

- Replaced Unicode placeholder/navigation icons that appeared as empty squares with resolution-independent vector icons drawn directly by egui.
- Windows Discover Apps now reads registered installed programs from the Windows uninstall registry (HKLM/HKCU, 32/64-bit views), using real DisplayName metadata rather than version folders.
- Unknown helpers, updaters and installer executables are no longer promoted to normal app entries.
- Resolved installed applications with DisplayIcon and InstallLocation where available; show unresolvable installed entries but disable automatic selection.
- Added read-only installed-application discovery tests and consistent action icons.

## Downloads

Binary archives for Windows x64, Linux x64, and macOS Apple Silicon ARM64 are available below, plus SHA256SUMS.txt. These are executables, not signed installers; macOS is not notarized.

## Limits

Windows Store/MSIX apps are not yet enumerated. Installed software may still rely on licenses, services, drivers or shared machine state. Profile-only mode is best effort except for apps with supported profile arguments. This is not an OS security sandbox or universal app virtualization.
