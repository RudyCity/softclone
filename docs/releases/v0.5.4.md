# SoftClone v0.5.4 — Debug Logs, About & Support Development

Add real local diagnostics to make future debugging and application analysis easier.

## New

- **Debug logs** sidebar page with event history for app discovery, clone preflight, creation/cancellation, process lifecycle, and instance management.
- Filter diagnostic events by All / Info / Warnings / Errors or search by event/category.
- View recent event and error counts, copy a sanitized diagnostic report, or manually export it as a plain text file.
- Clear local diagnostic history through a confirmation dialog.
- Add a separate **About SoftClone** page with version, OS, MIT license, repository link and Open data folder action. Existing **How it works** remains.
- Add optional **Support development** link to https://ko-fi.com/rudycity in the sidebar and About page.

## Privacy and limitations

Diagnostic events include only fixed event categories, levels and timestamps. The app intentionally does not log executable paths, account names, profile files, tokens or raw error messages. Logs remain on-device (JSONL, bounded to 128 KiB per active/rotated file and 500 in-memory entries) and are never uploaded. Export requires the user's explicit action. Diagnostics is operational event history, not a complete crash dump or OS trace. The Ko-fi link opens externally, and donations are optional.

## Downloads

Portable unsigned executables for Windows x64, macOS Apple Silicon (ARM64) and Linux x64, plus SHA256SUMS.txt. All three platforms must pass format, Clippy, unit tests and release build before publication.
