# SoftClone v0.5.3 — Discover search alignment

Small visual fix for the installed-application search toolbar.

- Aligned **Search installed applications** and **Rescan** along the same top edge.
- Matched the search field's total height to Rescan (35 pt) for consistent appearance.
- Adjusted icon and placeholder row geometry so the text no longer appears vertically offset.
- Kept responsive narrow-window behavior and all application discovery/clone features unchanged.
- Added an invariant test for the search-control height and retained cross-platform CI.

Downloads: Windows x64 ZIP, macOS ARM64 TAR.GZ, Linux x64 TAR.GZ, and SHA256SUMS.txt. Builds are unsigned portable executables, not installers.

Visual verification on the user's Windows desktop remains necessary for custom display scaling.
