# SoftClone v0.6.1 — Verified Tauri 2 desktop migration

SoftClone now ships a full native **Tauri 2** desktop application for Windows, macOS, and Linux, replacing egui/eframe while retaining the existing Rust+Rune cloning engine.

## What's included

- Local My clones, Create clone, Discover apps, Debug logs, How it works and About workspaces.
- Safe Rust command bridge with clone preflight, progress/cancel, process management, registry and backup/restore.
- Original SoftClone clone data stays compatible; no data migration is required.
- Apache License 2.0, full LICENSE and NOTICE resource bundling.
- Fix for restore-dialog selection stability, Rust host compilation, JavaScript syntax and automated formatting.
- CI runs Rust tests, lint, JS validation, three native desktop builds and package uploads.
- Release publishing is gated on all platforms succeeding **and** the build commit still matching main.

## Boundaries

Software vendor licensing, DRM, MSIX/Store sandboxing, OS services and app signatures are not bypassed. This is not a virtual machine or security sandbox. Unsigned native desktop packages may trigger operating-system warnings. The repository's GitHub Actions artifacts and release are the source of built binaries.
