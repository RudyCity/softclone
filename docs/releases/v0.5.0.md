# SoftClone v0.5.0 — Instance Manager

Manage app copies and profiles from the My clones workspace.

## New features

- **Launch / Stop / Restart:** track child processes spawned during the current session and display the tracked PID. Stop is limited to tracked child processes.
- **Rename:** update the instance label without moving files.
- **Duplicate:** make an independent managed copy of an instance folder without touching vendor binaries.
- **Backup:** create local snapshots of the managed directory and profile data, with backup-to-instance metadata.
- **Restore:** select a matching snapshot, stage the restore, and roll back folder swaps on failure where possible.
- **Delete:** confirm with the exact instance name, validate the library path, and remove managed files and the registry entry. Backups remain.
- **Tests:** verify rename, independent duplication, backup/restore, deletion, foreign backup and forged path rejection.

## Downloads

Archives provide binaries for Windows x64, Linux x64, and macOS Apple Silicon ARM64 with SHA256SUMS.txt. These are not signed installers.

## Important notes

Backups are unencrypted local directories and may contain sensitive personal app data. Do not share them without reviewing contents. Externally started applications cannot always be detected; close them before file operations. A macOS launcher process may exit before its GUI app, so the tracked PID can differ from the actual app PID. This release does not provide OS virtualization or license bypass.
