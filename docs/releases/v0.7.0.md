# SoftClone v0.7.0 — Update Center

This release adds **Updates**, a native user-approved installer workflow for Tauri 2 on Windows, macOS and Linux.

## Features

- Check the latest official stable GitHub release at startup (opt-out supported) or manually.
- Display current/latest versions, update availability, release notes, compatible native installer and size.
- Download from the exact official GitHub Releases asset URL with bounded size, byte progress and cancellation.
- Verify download size and SHA-256 against SHA256SUMS.txt; verify hash again immediately before opening the installer.
- Open the native Windows setup executable, macOS DMG or Linux AppImage only after user confirmation.
- Validate stable SemVer, reject downgrades, untrusted asset URLs, duplicates or invalid checksum entries, and incompatible architectures.
- No native shell command exposed to the frontend; only validated Rust updater commands.
- Add Rust unit tests for the checksum parser, installer allowlist and stable SemVer; run Tauri host tests on the platform CI matrix.

## Security model

No unattended in-place updates: Tauri's native auto-updater requires Ed25519 signing keys managed as secrets, and this project has no such configured signing infrastructure. The verified installer approach uses the official GitHub release and matching SHA256SUMS manifest; this hash is **not** an independent code-signing authority. Users must approve opening the installer and any OS elevation prompts. Clone data and profile registry remain unchanged.
