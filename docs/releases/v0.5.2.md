# SoftClone v0.5.2 — Windows Store and macOS App Store inventory

This release fixes disabled application cards in Discover Apps and recognizes Windows packaged apps separately from classic Win32 applications.

## Improvements

- **Windows AppX/MSIX:** detect user-registered packages and launchable app identities using Windows PowerShell's read-only package/Start menu APIs. Store-style packages show **Open app**, activating them normally through their AUMID instead of requiring a nonexistent standalone `.exe`.
- **macOS Mac App Store:** detect `.app` bundles with a Mac App Store receipt, label them correctly, and expose ordinary **Open app** activation.
- **Win32 executable detection:** add safer executable resolution for Illustrator, Android Studio, CapCut and OBSBOT Center, including versioned install directories.
- **Manual fallback:** unresolved Win32 app cards now offer **Locate executable…** to select the actual primary executable. OBS Advanced Scene Switcher is identified as a plugin rather than an app.
- **Regression tests:** AppX identity validation/JSON parsing, Mac App Store receipt recognition, and Windows primary-executable matching.

## Important compatibility boundary

**Open app does not mean Clone app.** MSIX/AppX apps and Mac App Store apps are opened through their operating systems. This release does not duplicate Store sandbox installations, evade licenses or supply separate user profiles for packaged apps. Some Win32 programs require proprietary services or do not support multiple independent processes. Microsoft Store packages may also be deployed outside the Store; package origin alone is not proof of a purchase.
