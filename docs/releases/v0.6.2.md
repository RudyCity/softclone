# SoftClone v0.6.2 — Fix unwanted Windows Terminal during app discovery

SoftClone remains a native Tauri 2 desktop app using the Rust and Rune cloning engine and existing registry.

## Fixes

- Windows Store/MSIX discovery starts PowerShell with `CREATE_NO_WINDOW`, `-WindowStyle Hidden`, `-NonInteractive`, and closed stdin, suppressing the visible terminal without interrupting the scan.
- The Tauri host uses the Windows GUI subsystem in debug and release builds.
- A Windows PowerShell runner test and a hidden-console source regression check guard this behavior.
- No clone registry migration, license change, or changes to clone and backup data.

## Verification

CI runs Rust tests and frontend checks, and builds Tauri installers on Windows, macOS and Linux. A real Windows desktop smoke test is required to visually verify no console windows appear when Discover apps is opened.
