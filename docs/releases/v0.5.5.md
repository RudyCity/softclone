# SoftClone v0.5.5 — Apache License 2.0

SoftClone now uses the **Apache License, Version 2.0** (`Apache-2.0`) for current source and binaries.

## Changes

- Replace the repository MIT `LICENSE` with the official Apache License 2.0 text.
- Add a project `NOTICE` file preserving the **Copyright 2026 RudyCity** attribution.
- Update Cargo's SPDX license field, README, About SoftClone and architecture documentation.
- Include `LICENSE` and `NOTICE` alongside the executable in **each** Windows, macOS and Linux release archive.
- Add automated regression checks for Apache license terms, Cargo metadata and attribution.

## Notes

Previously distributed MIT-licensed releases retain the terms under which those copies were provided. Third-party dependencies continue under their own licenses. The new project license does not change application behavior or require a donation. See the root LICENSE and NOTICE for details.

## Downloads

Download Windows x64 ZIP, macOS Apple Silicon ARM64 TAR.GZ or Linux x64 TAR.GZ, and optionally verify SHA256SUMS.txt. Each archive contains the portable binary plus Apache LICENSE and NOTICE.
